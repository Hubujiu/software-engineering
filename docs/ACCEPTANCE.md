- Python unittest：24 项通过（包括三个语言适配器、Graphify 导入边界、真实 Go/Python 进程、HTTP 重试、SQLite 读写、幂等、错误不重试和历史结果快照）。

## 浏览器限制

工作容器的 Chromium 策略禁止 URL 导航，因此本地真实页面的浏览器 E2E 在这里无法运行。离线测试通过 `set_content` 渲染导出文件，没有关闭或修改浏览器策略。真实 API/进程集成测试独立执行。

仓库提供 `tests/browser_smoke.py` 的完整在线路径，涵盖 iframe 选取、真实表单提交和图谱导入；GitHub Actions 工作流用于在可导航的云端浏览器环境执行。没有看到工作流成功结果之前，不将其写成已通过。

## 已知范围

- 示例分层、跨进程绑定、五项策略与字段映射为显式配置，不是对任意仓库的自动推断。
- Python/Go 调用解析有限；未解析的成员调用留在诊断中。TS 只用上传虚拟文件，不加载整个项目环境。
- 请求事件是显式采集的边界记录，不是逐条指令、所有变量或通用自动追踪。
- 页面示例是原生 JS；尚未实现 React Fiber 适配。
- 数据库只支持示例 SQLite 以及本次结果快照，不提供通用生产数据库血缘。
- 离线 HTML 仅回放已采集 GET 记录；没有伪造新的请求结果。
- 初版不会自动合并功能分支，等待用户检查交互方向。
